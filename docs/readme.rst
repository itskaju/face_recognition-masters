# 👤 Face Recognition System

A Python-based face recognition system that detects and identifies human faces using computer vision and machine learning.

---

## 🚀 Features
- Real-time face detection using webcam  
- Face recognition using trained encodings  
- Supports images and videos  
- Easy to use  

---

## 🛠️ Tech Stack
- Python  
- OpenCV  
- face_recognition  
- NumPy  

---

## ▶️ How to Run

```bash
git clone https://github.com/itskaju/face_recognition-masters.git
cd face_recognition-masters
pip install -r requirements.txt
python examples/face_recognition.py
